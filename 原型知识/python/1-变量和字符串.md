一、变量variable  
变量variable是一个名字，一个标签，通过变量可以找到对应的数据。  
Eg: x = 3  
它的名字是x,它的值是3  
（= 表示的是一个赋值操作，将3与变量名x进行挂钩）
 
当一个变量被创建之后，使用变量名就可以直接访问变量  
Eg:  
`\>\>\> x = 3` 
`\>\>\> print(x)`  
`3`
 
变量名通常由字母、数字、下划线构成，但不能以数字打头  
Eg:  
`loveyou1314 = 1314`  
`520baby = 520`  
`SyntaxError`
 
变量名区分大小写，ABC与Abc与ABc是不同的  
Pyhton3 变量支持中文  
Eg:  
`\>\>\> 幸运数 = 588`  
`\>\>\> print(幸运数)`  
`588`
 
变量的值是可变的,变量的值取决于最后一次赋值操作  
`\>\>\> name = “大狗”`  
`\>\>\>print(name)`  
`大狗`  
`\>\>\> name = “小狗”`  
`\>\>\>print(name)`  
`小狗`
 
不同变量的值可以进行传递  
eg：  
把x的值传递给y：  
`\>\>\> x = 3`  
`\>\>\> y = 5`  
`\>\>\> x = y`  
`\>\>\> print(y)`  
`3`  
把x和y的值都赋值为3：  
`\>\>\> x = y = 3`  
`\>\>\> x`  
`\>\>\> 3`  
`\>\>\> y`  
`\>\>\> 3`  
需要交换两个变量之间的值,要让x里存放y的值，y里存放x的值，需要一个临时变量z  
`\>\>\>x = 3`  
`\>\>\>y = 5`  
`\>\>\>z = x`  
`\>\>\>x = y`  
`\>\>\>y = z`  
`\>\>\>print(x,y)`  
`5 3`  
`\>\>\>x = 3`  
`\>\>\>y = 5`  
`\>\>\>x, y = y, x`  
`\>\>\>Print(x,y)`  
`5 3`
