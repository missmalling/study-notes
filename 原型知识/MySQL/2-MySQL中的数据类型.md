MySQL数据类型：  
整数类型：  
常用类型:tinyint int
 
浮点数类型：  
常用类型:float double
 
字符类型：  
常用类型:char varchar text
 
日期类型：  
常用类型:date time datatime
 
二进制类型：  
常用类型:BLOB
   

MySQL数据类型

|   |   |
|---|---|
|整数类型|含义(有符号)|
|tinyint(m)|1个字节范围(-128~127)性别，01表示|
|smallint(m)|2个字节 范围(-32768~32767)|
|mediumint(m)|3个字节 范围(-8388608~8388607)|
|int(m)|4个字节 范围(-2147483648~2147483647)|
|bigint(m)|8个字节范围(+-9.22*10的18次方)|

数值类型中的长度m是指显示长度,并不表示存储长度,只有字段指定zerofill时有用  
例如:int(3),如果实际值是2,如果列指定了zerofill,查询结果就是002,左边用0来  
填充
 
浮点类型

|   |   |
|---|---|
|MySQL数据类型|含义|
|float(m,d)|单精度浮点型8位精度(4字节)m总个数,d小数位  <br>5,3：总个数5，小数位2，所以整数位是3|
|double(m,d)|双精度浮点型16位精度(8字节)m总个数,d小数位|
 
字符类型

|   |   |
|---|---|
|MySQL数据类型|含义|
|char(n)|固定长度,最多255个字符。n表示当前字符的总长度。5，给一个a，前四个字符会用空格补齐|
|tinytext|可变长度,最多255个字符|
|varchar(n)|可变长度,最多65535个字符。n表示当前字符的总长度。5，给一个a，前四个字符不会用空格补齐，只是一个a|
|text|可变长度,最多65535个字符|
|mediumtext|可变长度,最多2的24次方-1个字符|
|longtext|可变长度,最多2的32次方-1个字符|

整数数据类型不是一定要给一个括号并指定n,但char和varchar一定要给一个括号并指定n
 
char和varchar:  
1 char长度固定,即每条数据占用等长字节空间;适合用在身份证号码、手机号码等  
定长。  
2 varchar可变长度,可以设置最大长度;适合用在长度可变的属性。  
3 text不设置长度,当不知道属性的最大长度时,适合用text。  
按照查询速度:char最快,varchar次之,text最慢。
 
字符串型使用建议:
 
1经常变化的字段用varchar  
2 知道固定长度的用char  
3 尽量用varchar  
4超过255字符的只能用varchar或者text  
5 能用varchar的地方不用text
 
日期类型

|   |   |
|---|---|
|MySQL数据类型|含义|
|date|日期 YYYY-MM-DD|
|time|时间 HH:MM:SS|
|datetime|日期时间 YYYY-MM-DD HH:MM:SS|
|timestamp不考虑时区，按格林尼治天文台的算|时间戳YYYYMMDD HHMMSS|
 
二进制数据(BLOB)用于存储图像、影音或超过250字的大文本
 
1 BLOB和TEXT存储方式不同,TEXT以文本方式存储,英文存储区分大小写,而Blob是以  
二进制方式存储即以字节方式存储,不分大小写。  
2 BLOB存储的数据只能整体读出。
 
3 TEXT可以指定字符集因为TEXT基于字符类型来存储,BLOB不用指定字符集。
