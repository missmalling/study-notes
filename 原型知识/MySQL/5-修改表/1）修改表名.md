修改表名  
ALTER TABLE 修改表关键字  
旧表名 旧表名  
RENAME 修改表名关键字  
新表名； 新表名
 
使用DDL语句修改表  
ALTER TABLE  
旧表名 RENAME  
新表名;  
示例一:  
创建一个employees表包含雇员ID,雇员名字,雇员薪水。  
`create table employees(employee_id int, employee_name varchar(10),salary float(8,2));`  
示例二:  
将employees表名修改为emp。  
`alter table employees rename emp;`
