Tab：切换物体模式 / 编辑模式

物体模式与编辑模式：
1.物体模式是物体级的整体操作，把每个立方体 / 模型当成一个独立的完整单元；编辑模式是网格级的细节编辑，深入单个物体内部，修改它的顶点、边、面
2.物体模式负责整体布局：移动物体位置、调整整体大小角度、添加修改器、复制 / 删除物体、赋予材质；
编辑模式负责造型细节：修改模型形状、调整布线、挤出厚度、打磨局部结构，决定模型本身长什么样。
3.物体模式下：G 移动整个物体，Shift+D生成一个全新的独立物体；
编辑模式下：G只移动选中的顶点 / 边 / 面，Shift+D只在同一物体内复制网格元素，不会产生新物体。即左侧场景中不会新增立方体。
4.按 Tab是两种模式的切换键，但必须先在物体模式选中目标物体，才能进入它的编辑模式。

表面细分修改器（Subdivision Surface）
表面细分（常简称「细分 / Subsurf」）是 Blender非破坏性曲面建模的核心工具，它会自动给低面数的棱角模型增加网格面数，同时平滑所有生硬边角，把方块感的基础模型变成流畅的曲面造型，全程不会永久修改原始网格，参数随时可调整。
核心用途：
- 制作圆润的有机造型：角色、玩偶、曲面摆件
- 柔和化硬表面模型：给家具、电子产品、容器做自然圆角，提升真实感
- 配合卡线制作软硬过渡的造型：比如沙发扶手、家电外壳

 环切（快捷键 Ctrl+R）
 是编辑模式下的循环切割布线工具，能在连续的四边形网格上，自动切割出一整圈首尾相连的边线，同时将途经的每个面一分为二。它全程不破坏模型拓扑，是调整布线、控制细分曲面圆角的核心操作。 
 一、基础操作完整步骤 
 1. 选中物体后按 Tab进入编辑模式，无需提前选任何元素。 
 2. 按下 `Ctrl+R`，将鼠标悬停在目标面上，模型上会出现粉色的预览环线。
 3. 滚动鼠标滚轮，可以增加/减少切割的圈数（默认1圈）。 
 4. 单击鼠标左键确认环线的走向，此时进入位置滑动状态，拖动鼠标可调整环线的位置。
 5. 位置调整满意后，再次单击左键完成切割；右键点击则直接取消操作。
 二、作用 
 配合表面细分「卡线」控圆角，单纯添加表面细分会让所有边角变成大圆角，造型发软；用环切在靠近边缘的位置加一圈线，就能约束曲面的变形范围。
 环线离边缘越近，细分后的圆角越小、边角越硬挺；环线离边缘越远，细分后的圆角越大、曲面越柔和。 
 一次切2条线分别贴在边角两侧，能得到规整的硬边倒角效果，是家具、产品建模的标准做法 ### 2. 增加网格分段，支撑细节造型 模型要做挤出凸起、弯曲变形、局部缩放等操作时，必须有足够的布线支撑。环切可以快速给模型增加横向/纵向的分段，让后续变形更平滑，不会出现生硬折角。 3. 拆分结构，调整模型比例 把一个完整的面切割成多份后，可以单独选中其中一部分移动、缩放，快速拆分模型的结构比例。比如给立方体横向切一刀，就能分别调整上下两部分的高度。
   四、常见问题
1.切不出完整一圈线 循环边只能在连续的四边形面上环绕，如果网格里有三角面、五边面，或是模型有破洞、开口，都会打断循环路径，导致环线中途断开。解决方法是先修复布线，尽量保持网格以四边面为主。
2.和刀切（K键）的区别- 环切：自动沿循环路径整圈切割，规则高效，适合标准布线、批量加线 - 刀切（K键）：手动自由绘制切割路径，灵活但不规则，仅适合局部特殊加线
3.避免过度加线布线遵循「够用就好」原则，过多的环线会增加后续调整的复杂度，也会让表面细分后的面数成倍增长，导致操作卡顿。 

 倒角修改器（Bevel）：
 是非破坏性优化模型边缘的核心工具，它可以自动给模型的尖锐棱角磨出均匀的圆角或斜面，模拟现实物体的自然边缘，避免渲染时出现生硬、虚假的直角反光。 
  一、
   **本质**：在不破坏原始网格的前提下，给模型的边线自动增加分段、做出过渡弧度，所有参数可随时调整。
二、核心参数逐项讲解 
1. 倒角量（Amount） 控制倒角的大小，数值越大，圆角/斜面越宽。一般搭配「偏移类型」使用——它以边缘到倒角起点的距离为单位，最符合直观认知。 
2. 2. 段数（Segments） 控制倒角的平滑程度： - 1段：生成平面斜面（45°切角） - 3-5段：生成圆润的圆角，段数越多弧度越自然。一般3段
3.  3. 角度限制（Angle Limit）:
筛选开关，开启后只有夹角大于设定角度的边才会被倒角。例如设置为60°：模型上90°的硬边会被倒角，而平面上的平边（180°）不会被多余处理
4. 限制方法
更精准的控制方式： 
- 权重：配合编辑模式下的边权重，手动控制每条边的倒角强度 
-  顶点组：只对指定顶点组范围内的边生效，适合局部精准倒角 
- 材质：按材质ID区分倒角范围 
-  5. 轮廓（Profile） 控制倒角的截面弧度，数值0-1： - 0：直线斜面，无圆弧过渡 - 0.5：标准圆弧，最接近现实物体的圆角 - 1：内凹形倒角，适合特殊造型
五、常见问题
1. 倒角后出现穿插、破面：倒角量设置过大，超过了相邻面的宽度，调小倒角量即可解决。 
2.  不该倒角的边也被处理了：开启「角度限制」，适当调大角度阈值（如60°-80°），只对硬边生效。
3.  3. 圆角不圆滑、有棱角：增加「段数」数值，同时确认倒角修改器在表面细分之后（要精致硬边的场景）。 

平滑着色
是光影显示优化功能，它通过调整顶点法线的计算方式，让相邻面片之间的光影过渡变得柔和，视觉上消除生硬的棱线，让模型看起来更圆润光滑。它属于「视觉层面的柔化」，不会改变模型的顶点数量和面数，也不会修改模型的实际几何形状
