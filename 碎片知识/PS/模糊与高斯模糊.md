一、基础定义区分
1. 普通「模糊」/「进一步模糊」（简易均值模糊）
原理：把选区周围所有像素同等权重平均，离中心远、近的像素影响完全一样。
- 无参数可调，点一下直接生效；
- 模糊力度固定：「模糊」轻微降噪，「进一步模糊」强度约是它4倍；
- 视觉缺陷：过渡生硬，边缘会出现方块阶梯感，很假，没有自然渐变衰减。
 
2. 高斯模糊（专业可控模糊）
原理：按照高斯钟形曲线加权，离中心越近的像素影响越大，越远影响越弱，模拟真实镜头虚化、毛玻璃渐变效果 。
- 自带半径滑块，0.1~250像素自由调节模糊强弱；
- 过渡柔和顺滑，明暗、色彩渐变自然，无方块锯齿，修图通用首选。
 
二、核心差异对照表

|      | 普通模糊            | 高斯模糊                   |
| ---- | --------------- | ---------------------- |
| 参数控制 | 无任何可调参数，力度固定    | 可拖动半径，自由控制虚化强弱         |
| 模糊过渡 | 均等平均，边缘生硬、方块感   | 中心重、外围渐淡，渐变柔和自然        |
| 真实感  | 数码感强，不像相机原生虚化   | 贴近镜头景深、柔光实拍效果          |
| 适用场景 | 仅轻微去除图片细小杂色、摩尔纹 | 背景虚化、暗角、蒙版柔化、皮肤柔光、朦胧氛围 |
| 可控性  | 完全不可控，效果一次性     | 精细微调，可反复调整             |
 
三、用途
 
什么时候用普通模糊（几乎很少用）
 
只有图片扫描有细小网点、少量颗粒噪点，只想轻微弱化杂色，且不需要柔和过渡时用；人像、背景虚化绝对不推荐，边缘会割裂违和。
 
什么时候用高斯模糊（90%修图场景都靠它）
1. 虚化杂乱背景
选中草丛、多余建筑，高斯模糊半径5–15，模拟大光圈浅景深，主体突出，过渡自然不生硬；
2. 蒙版光影柔化
搭配之前学的羽化，给明暗调整层蒙版做高斯模糊，提亮人脸、压暗杂草不会出现一块一块硬色块；
3. 柔化皮肤/制造柔光氛围
低半径1–3轻微模糊皮肤，保留五官轮廓，打造通透柔和质感；
4. 暗角制作
椭圆反向选区+大半径高斯模糊，画面四周均匀压暗，视线集中在人物/猫咪；
5. 遮挡水印、杂物
高斯模糊遮挡文字、多余路人，渐变模糊不会一眼看出修补痕迹。
 
四、实操避坑总结
1. 普通模糊属于一键简易工具，无精细调节，只适合轻微降噪；
2. 只要需要「柔和渐变虚化」，一律用高斯模糊，可控、画面更专业；
3. 高斯模糊搭配选区羽化一起用，虚化边缘融合度会再提升一个档次。
