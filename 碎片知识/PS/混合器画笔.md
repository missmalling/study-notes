PS混合器画笔工具完整详解
一、基础定位与调出方式
1. 工具本质
模拟真实水彩、油画颜料混色逻辑，落笔时同时抓取画布原有色彩+画笔自带颜料，双向自动晕染融合，核心作用是揉匀色块、柔和光影过渡，不能复制画面纹理、无法删除杂物 。
2. 调出位置
工具栏长按「普通画笔工具」，弹出菜单最后一项；快捷键统一为 B 。
3. 基础操作
按住 Alt 吸取画面干净肤色/草地色彩存入画笔储槽，松开直接涂抹，拖动时颜色会自然渐变、和底色相融。
 
二、四大核心专属参数（修图标准设置）
1. 潮湿（Wet）
 
画布“含水量”，数值越高，越容易把画面原有颜色推开、大范围晕染；
- 人像磨皮：20–40
- 统一斑驳草地/天空：60–80
- 0=完全不混色，仅平铺纯色，失去混合器画笔作用。
 
2. 载入（Load）
画笔储存颜料的多少，控制前景色输入量；
- 只揉匀原图光影、不加新颜色：载入设0
- 需要轻微提亮肤色：载入20–30。
 
3. 混合（Mix）
画笔颜料与画布底色融合比例，数值越高，底色参与混合越多；
人像/风景统一光影标准值：20–40。
 
4. 清理画笔
勾选后，每一笔结束自动清空笔内残留色彩，避免不同区域串色，人像精修建议始终勾选。
 
三、和普通画笔、仿制图章核心区别
 
5. 对比普通画笔
- 普通画笔：只单向铺前景色，不会主动融合底色，过渡生硬，适合蒙版、画线；
- 混合器画笔：自动双向混色，笔触自带柔和渐变，专门抹平斑驳色块、柔化光影断层。
 
2. 对比仿制图章
- 仿制图章：Alt取样完整复制纹理，用来去除杂草、落叶、修补背景，保留细节；
- 混合器画笔：无复制功能，只能揉匀色彩，大面积涂抹会模糊毛发、皮肤纹理，不能清除画面实体杂物。
 
四、实拍修图四大实用场景
 
1. 人像柔和磨皮（高频用法）
高低频分层的低频图层使用，揉匀痘印、泛红、面部明暗褶皱，保留五官轮廓，不会像高斯模糊一样糊掉五官；
参数参考：潮湿25，载入20，混合30，低流量反复轻涂。
 
2. 统一杂乱背景色调
林间斑驳青草、明暗不均墙面、断层天空，涂抹后深浅色块自然融合，画面干净通透，弱化杂乱视觉干扰。
 
3. 柔和生硬光影交界
树荫分割人脸、树干明暗分界线、衣服褶皱硬色块，轻轻涂抹消除明暗割裂，过渡自然。
 
4. 氛围感艺术化处理
整张图低强度扫涂，做出油画、朦胧胶片质感。
 
五、实操避坑要点
1. 不要在毛发、五官高频细节图层使用，会直接糊掉睫毛、皮肤毛孔等细节；
2. 大面积晕染降低流量，少量多次涂抹，避免一次性涂抹过度画面发灰；
3. 修图流程顺序：先用仿制图章清除杂草杂物→再用混合器画笔统一光影肤色；
4. 处理分层图片时，低频层使用混合器画笔，高频纹理层只用仿制图章修复瑕疵。
