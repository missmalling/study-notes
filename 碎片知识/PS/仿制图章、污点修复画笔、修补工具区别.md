核心原理与基础操作对比 
1. 污点修复画笔（快捷键J，懒人一键修复）
原理：无需手动Alt取样，涂抹瑕疵后软件自动抓取周边像素，智能融合光影、色彩、纹理。
操作：调整画笔略大于瑕疵，直接点涂/涂抹脏点即可。
特点：全自动、最快；只适合小面积、背景单一区域。
短板：复杂纹理、明暗交界、大面积杂物极易糊掉、出现色块错乱。

2. 修补工具（快捷键J，选区式批量修复）
原理：先用套索画出需要去掉的区域，再拖动选区到干净纹理处，软件自动匹配光影过渡。
操作：圈选杂物→拖动到完好背景，松开自动融合。
特点：适合成片、大块瑕疵（一堆落叶、多条杂草、大片痘印），一次性处理一片，效率高。
短板：精细发丝、五官边缘容易扭曲变形。

3. 仿制图章（快捷键S，精准可控手工复制）
原理：按住 Alt 手动指定取样区域，原样复制像素，不会自动融合色调，纹理1:1复刻。
操作：Alt点干净处取样，松开涂抹覆盖瑕疵；可调节硬度、不透明度控制融合度。
特点：完全可控，不会自动糊画面，适合边缘、规律纹理、精细修复。
短板：需要手动取样，操作最慢，纯新手容易复制重复花纹显假。
 
二、三大工具核心差异对照表
 

|               | 污点修复画笔           | 修补工具            | 仿制图章           |
| ------------- | ---------------- | --------------- | -------------- |
| 是否手动取样        | 不用，自动采样          | 画选区拖动采样         | Alt手动取样        |
| 修复面积          | 极小单点（痘痘、灰尘、细小草丝） | 成片大块（一堆落叶、成片杂草） | 不限大小，精细局部最优    |
| 融合逻辑          | 自动匹配明暗色彩，柔和融合    | 选区整体智能过渡        | 原样复制像素，无自动融合   |
| 边缘精细度         | 差，明暗交界易糊         | 中等，大面积好用、细线易扭曲  | 极高，发丝、轮廓、分界线专用 |
| 规律纹理修复（墙面/草地） | 容易变形错乱           | 大面积纹理尚可，细纹路不行   | 完美复刻，不会错位      |
| 操作难度          | 最低，一键涂抹          | 中等，套索选区操作       | 最高，需要控制取样与画笔参数 |

三、用途
 
4. 污点修复画笔
- 人像：单颗痘痘、小黑痣、镜头灰尘小点；
- 动物/风景：单根细杂草、零星小黄落叶、小污渍；
- 前提：周围背景颜色、纹理统一（平整草地、干净皮肤）。
 
2. 修补工具（批量去除大片杂物）
- 路面一堆落叶、成片杂乱长草；
- 脸颊成片痘印、背景多余杂物、墙角空调外机；
- 适合一次性清理一整块干扰元素，大幅节省时间。
4. 仿制图章（精细、边缘、规律纹理）
1. 主体边缘修复（最核心用途）
主体旁边挡视线的杂物、衣服轮廓，不会把边缘糊花；
2. 重复规整纹理
草地、砖墙、木纹路面，完美复刻纹理，不会出现色块断层；
3. 精细皮肤过渡
低不透明度（30%-60%）轻涂，保留皮肤毛孔质感；
4. 复杂明暗交界
树干、门窗阴影、逆光轮廓，不受自动融合算法干扰，画面干净真实。
 
四、实操搭配技巧
1. 先拿污点修复清理所有零星小点灰尘；
2. 大面积杂草、落叶用修补工具批量清除；
3. 五官、毛发、画面分界线、纹理重复区域，全部用仿制图章精细收尾；
4. 仿制图章画笔硬度调20%-40%，搭配低不透明度，修复边缘自然无硬白边；
5. 所有修复新建空白图层，取样勾选「所有图层」，原图永久保留。
 
极简一句话区分
 
- 小脏点、省事一键修 → 污点修复画笔
- 一大片杂物、批量清理 → 修补工具
- 精细边缘、纹理、怕画面糊掉、追求精准可控 → 仿制图章
